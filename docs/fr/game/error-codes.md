# Codes d'erreurs

Cette page répertorie tous les codes d’erreur que le lanceur peut afficher.

---

| Code                                                                                | Description                                                                                                               | Solution possible                                                                                                                                                                                                      |
|-------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 10048                                                                               | Quelque chose d'autre utilise le port du lanceur                                                                               | Assurez-vous que le lanceur n'est executé qu'une seule fois. Essayer de redémarer votre ordinateur.
| 10038 / 10060 / 10061                                                               | Aucun serveur n'a répondu sur cette adresse IP et / ou port                                                                                  | Si vous êtes le propriétaire du serveur, vérifiez la redirection de port et/ou les règles du pare-feu. Vous trouverez davantage d’informations à ce sujet dans la documentation du [serveur BeamMP](https://docs.beammp.com/server/create-a-server).

Si vous n’êtes pas le propriétaire du serveur, essayez de rejoindre un autre serveur ou contactez le propriétaire du serveur si vous le connaissez.

| 10054                                                                               | La connexion a été interrompue par le serveur distant.                                                                           | Le serveur auquel vous tentez de vous connecter est hors ligne.                                                                                                                                                                   |
| Failed to find the game please launch it. Report this if the issue persists code 3. | Le lanceur n'a pas été capable de trouver les informations du jeu (répertoire du jeu, répertoire de profils, version, etc.) dans le registre.                        | Lancez le jeu au moins une fois pour que les valeurs du registre puissent être créées.                                                                                                                                                         |
| Failed to find the game please launch it. Report this if the issue persists code 4. |Le lanceur n’a pas pu trouver dans le registre les informations nécessaires concernant le jeu, telles que le répertoire d’installation, le répertoire des profils, la version du jeu, etc.
 | Cette erreur survient principalement lorsque l’utilisateur possède une copie piratée du jeu. Si vous avez acheté le jeu, lancez-le au moins une fois afin que les informations nécessaires soient créées dans le registre.
                                               |
| Failed to Launch the game! launcher closing soon                                    | Le lanceur n'a pas été capable de trouver l'exécutable (.exe) du jeu                                                                                  | Lancer le jeu BeamNG.drive au moins une fois avant de lancer le lanceur BeamMP.                                                                                                                                                          |
| Game Closed! launcher closing soon                                                  | Le jeu a été fermé                                                                                 | Ce message apparait lorsque le jeu est fermé ou lorsque le jeu ne réussit pas à se lancer.                                                                                                                                             |
| Launcher Update failed!                                                             | Le lanceur n'a pas réussit à télécharger une nouvelle version                                                                                | Vérifiez votre connexion Internet ainsi que les règles de votre pare-feu et de votre antivirus, et assurez-vous que BeamMP n’est pas bloqué.
                                                                                                                    |
| Logger file init failed                                                             | Le lanceur ne peut pas créer de fichiers                                                                              | Exécuter le lanceur en tant qu'administrateur.                                                                                                                                                                                     |
| Please close the game and try again                                                 | Le jeu est déjà lancé et le lanceur ne peut pas nettoyer le dossier `multiplayer/mods`                                                                                 | Fermez le jeu et réessayer.                                                                                                                                                                                              |
| Lancer le jeu au moins une fois.                                                    | Le lanceur a tenté de modifier les fichiers du répertoir du jeu et a échoué                                                                                | Lancer le jeu au moins une fois avant the lancer BeamMP.                                                                                                                                                                                  |
| Primary Servers Offline! Sorry for the inconvenience!                               | Le lanceur n'a pas réussit à vérifier si il y a une mise à jour                                                                                  | Vérifiez votre connexion internet ainsi que les règles de votre pare-feu. Si aucun problème ne semble provenir de votre côté, consultez le salon [BeamMP Updates](https://discord.com/channels/601558901657305098/1488185488925004079) sur notre serveur Discord afin de vérifier si une maintenance ou une panne est en cours.
 |
| Sorry Backend System Outage! Don't worry it will back on soon!                      | L'infrastructure en arrière-plan n’a pas répondu.                                                       |  Vérifiez votre connexion internet ainsi que les règles de votre pare-feu. Si aucun problème ne semble provenir de votre côté, consultez le canal [BeamMP Updates](https://discord.com/channels/601558901657305098/1488185488925004079) sur notre serveur Discord.
 |
| Stuck on updating                                                                   | Le lanceur reste bloqué sur « Updating » et ne passe pas à l’étape suivante.                                                                    | Exécuter le lanceur en tant qu'administrateur, vérifier les règles de votre antivirus et assurez-vous que le lanceur ne soit pas bloqué.                                                                                                       |
!!!note "" 
        
    Si le lanceur se ferme immédiatement, vérifiez le fichier `Launcher.log` dans le dossiers où vous avez installé BeamMP.
